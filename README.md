# Aura & Oak

A premium Shopify theme for hand-poured soy candles, ceramic diffusers, and artisan home fragrances.

## Features

- **Mega menu navigation** — 3-column dropdown for Shop, Studio, and Help categories
- **Full mobile menu** with accordions
- **9 homepage sections** — hero, marquee, category tiles, featured products, story, testimonials, journal preview, lookbook, newsletter
- **10 custom page templates** — Our Story, Sustainability, FAQ, Contact, Wholesale, Candle Care, Gift Guide, Lookbook, Journal, Shipping & Returns
- **Full commerce** — collection filters (category + scent), product pages with variant picker, cart page, AJAX cart drawer
- **Customer accounts** — login, register, account, order history, addresses, password reset
- **Blog/article templates**
- **Premium animations** — scroll reveals, stagger animations, parallax hero, marquee ticker, page fade-in
- **Fully responsive** — mobile-first breakpoints at 560px, 900px, 1000px
- **Persistent cart** with free shipping progress bar
- **AJAX add to cart** with toast notifications

## Installation

1. In Shopify Admin → Online Store → Themes → Add theme → Connect to GitHub
2. Select this repository
3. Create 5 collections with handles: `candles`, `diffusers`, `home-fragrance`, `gift-ideas`, `accessories`
4. Create pages with the corresponding template for each content section
5. Publish the theme

## Typography

- **Display**: Fraunces (serif) — elegant, editorial
- **Body**: Inter (sans) — clean, readable

## Color palette

- Cream `#FAF6F0` — backgrounds
- Ink `#211D19` — text, buttons
- Oak `#9C6B45` — accent, links on hover
- Clay `#B5714F` — sale badges
- Sage `#7D8B74` — success states
